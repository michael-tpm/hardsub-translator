# Contributing

Thanks for helping! Bug reports, subtitle samples and pull requests are all welcome.

- **Bugs:** open an issue with the command, its output and, if possible, a crop of the review or compare sheet.
- **New subtitle styles or languages:** a short sample clip (that you have the right to share) is the most useful thing you can give.
- **Pull requests:** keep changes focused. Before opening one, run the four steps on a short clip and make sure `./dich.sh verify` exits with code 0.

Good first areas: Windows/Linux OCR backend (RapidOCR), coloured subtitle masks, batch mode. See the Roadmap in the README.
